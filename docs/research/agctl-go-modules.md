### 6. Go 1.27 JSON packages

- **Available by default in Go 1.27; no GOEXPERIMENT=jsonv2 opt-in.** Release notes explicitly introduce both packages and make v1 use the new implementation; `GOEXPERIMENT=nojsonv2` is a temporary opt-out for v1 compatibility. The notes do not use the word GA, but these are no longer opt-in experimental imports. Local go1.27.1 documentation lookup with GOEXPERIMENT empty independently succeeded. Imports: `encoding/json/v2`, `encoding/json/jsontext`; standard Go BSD-3-Clause license. [Go 1.27 notes](https://go.dev/doc/go1.27), [Go license](https://github.com/golang/go/blob/go1.27.1/LICENSE).
- Verified syntax APIs: `jsontext.NewDecoder(io.Reader,...Options) *Decoder`; `(*Decoder).ReadToken() (Token,error)`; `.ReadValue() (Value,error)`; `.InputOffset() int64`; `jsontext.NewEncoder(io.Writer,...Options) *Encoder`; `(*Encoder).WriteToken(Token) error`; `.WriteValue(Value) error`; `type Value []byte`; `(*Value).Canonicalize(...Options) error`; `(*Value).Format(...Options) error`. [jsontext](https://pkg.go.dev/encoding/json/jsontext).
- Verified semantic APIs: `json.MarshalWrite(out io.Writer, in any, opts ...Options) error`; `json.UnmarshalRead(in io.Reader, out any, opts ...Options) error`; `json.DefaultOptionsV2() Options`; `omitzero` uses Go zero value or IsZero method and affects marshaling only. Default v2 rejects duplicate object names and invalid UTF-8. [json/v2](https://pkg.go.dev/encoding/json/v2).
- **Lossless-edit blocker to avoid:** token re-encoding preserves sequence/key order, not original lexical form or whitespace. ReadValue preserves exact bytes *inside* the value but strips surrounding whitespace; its buffer expires at the next Peek/Read/Skip. **WriteValue explicitly parses/reformats, not verbatim copies.** Format rewrites whitespace/escapes; Canonicalize applies RFC 8785, sorts keys and canonicalizes numbers, potentially losing numeric precision. None is a byte-preserving file editor. [ReadValue](https://pkg.go.dev/encoding/json/jsontext#Decoder.ReadValue), [WriteValue](https://pkg.go.dev/encoding/json/jsontext#Encoder.WriteValue), [Canonicalize](https://pkg.go.dev/encoding/json/jsontext#Value.Canonicalize).
- Therefore use the decoder for validation/location, retain the original []byte plus edit spans, and splice only selected replacements; return original bytes when unchanged. InputOffset is the end of the last token/value, not a ready-made start offset (commas/colons/whitespace intervene). This is a design recommendation derived from the documented boundaries, not an existing jsontext patch API.

### 8. HTTP failure classification

- Stdlib imports: `net/http/httptrace`, `net`, `net/url`, `context`, `io`, `errors`. Hooks: `ClientTrace.WroteRequest func(WroteRequestInfo)`, `WroteRequestInfo.Err error`, `GotFirstResponseByte func()`, `WithClientTrace(context.Context,*ClientTrace) context.Context`. WroteRequest reports writing outcome and may fire multiple times on retries; callbacks can run concurrently and after request completion/failure. [Trace docs](https://pkg.go.dev/net/http/httptrace).
- `Client.Do` errors are `*url.Error`; inspect Timeout() and Unwrap()/errors.As, then `*net.OpError` (Op/Err), `errors.Is(err, context.DeadlineExceeded)`, and `errors.Is(err, io.ErrUnexpectedEOF)` as relevant. HTTP non-2xx does not itself cause Do to return an error. [Client.Do](https://pkg.go.dev/net/http#Client.Do), [url.Error](https://pkg.go.dev/net/url#Error), [net.OpError](https://pkg.go.dev/net#OpError), [context](https://pkg.go.dev/context#DeadlineExceeded), [io](https://pkg.go.dev/io#ErrUnexpectedEOF).
- **Do not infer origin-side commit from error type or trace hook.** WroteRequest nil is not an application acknowledgment; WroteRequest error can follow a partial write; first response byte proves response activity from an HTTP peer, not that the origin completed the operation (proxies/early errors exist). A failed POST after possible transmission is **outcome unknown** unless the server offers idempotency/reconciliation. Only independently established pre-transmission failure justifies a not-sent classification; timeout alone does not.
- Exact documented Transport retry rule: network error + previously successful connection + request considered idempotent + no body or GetBody available. Methods listed are **GET, HEAD, OPTIONS, TRACE**, or presence of Idempotency-Key/X-Idempotency-Key. **Do not add PUT/DELETE to the documented implementation list just because HTTP semantics call them idempotent.** Zero-length header slice enables idempotent treatment without sending the header. [Transport](https://pkg.go.dev/net/http#Transport); also verified with local go1.27.1 go doc.
- Optional HTTP/2 import `golang.org/x/net/http2`: `StreamError{StreamID uint32, Code ErrCode, Cause error}`, `.Error() string`; x/net latest **v0.59.0, 2026-09-08**, BSD-3-Clause. Docs say Go 1.27 defaults to a net/http wrapper, with `http2legacy` selecting the original implementation. Do not assume every stdlib HTTP/2 error matches this exported concrete type. Avoid string-based classification; unrecognized stream errors remain outcome unknown. [HTTP2 API/license](https://pkg.go.dev/golang.org/x/net/http2), [version](https://proxy.golang.org/golang.org/x/net/@latest).
